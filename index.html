How to publish with GitHub Pages

  1. Create a new public repository on GitHub, for example visionmate-ai.
  2. Extract this ZIP and upload all files and folders to the repository's main branch.
  3. Open Settings → Pages.
  4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
  5. Open the published GitHub Pages link. Allow camera permission when prompted.
